    AIと一緒に考え、初心者目線で作り上げたSQL学習ゲーム
    背景・制作のきっかけ

    SQLの学習後、ゲーム感覚で学べるサービスをいくつか試しましたが、英語中心だったり、JOINが早々に出てきたりと、つまづいてしまいました。
    「初心者に優しく、日本語で練習しながら学べる教材があったらいいのに…。自分で作ってみよう。」と思い、自分の練習も兼ねて制作を始めました。
    題材には、貿易関連の資格知識や空港・税関・コンテナ現場のイメージからインスピレーションを得て、学んだ「容量偽装USB」も取り入れています。匿名告発をもとに「TECH-26」USBメモリの輸入取引やコンテナ保管記録を追い、不正の証拠を絞り込んでいく捜査型のSQL学習ゲームとして形にしました。

    工夫した点・苦労した点

    特に意識したのは、少しずつ理解を積み重ねられる出題順とストーリーのつながりです。基本的なSELECTから始まり、WHERE・ORDER BY・LIMIT・比較演算子・集計関数・GROUP BY・JOIN / LEFT JOIN・CASE WHEN、さらにはサブクエリや複数条件の整理・最終照合へと段階的に広がる問題を考えました。
    各問題にストーリー会話や「表A / カラム」の骨組みを示す段階的なヒント、解説を用意し、丸暗記ではなく自分で考えながら進められる教材を目指しています。データ生成の偏りやわずかな数量ズレなど、実際に解いたときの絞り込みやすさにも手を入れて調整しました。

    AIの活用について

    生成AIはコード作成の補助だけでなく、企画やカリキュラムを一緒に考える相談相手として活用しました。
    最初から丸投げするのではなく、自分のアイデアや疑問を言葉にして伝え、提案をもとに何度も調整を重ねています。問題構成のバランスやCASE WHENで分類してから特定対象へ絞り込む流れ、JOIN図解やテーブル確認の工夫といったアイデアも、AIとの対話から生まれました。
    提案をそのまま採用せず「初心者にとって本当に分かりやすいか？」「答えを出しすぎていないか？」と問い直し続けたことで、AIは考えを整理し、アイデアを具体的な機能へ一緒に育ててくれる心強いパートナーになると実感しました。

    今後の課題・目標

    AIのおかげでアイデアを形にするスピードはぐっと上がりましたが、作られたコードの仕組みを自分自身で十分に理解しきれていない点が課題です。
    これからはAIが書いたコードを一つひとつ読み解き、HTML・CSS・JavaScriptの役割や処理の流れをしっかり理解したいです。AIに頼りきるのではなく、提案を自分で判断・修正しながら、自力でも同等のアプリを設計・開発できる力を身につけるのが目標です。
    自分がSQLで感じた「難しさ」を忘れず、これから学ぶ人が楽しく取り組める教材へとアップデートし続けていきます。
