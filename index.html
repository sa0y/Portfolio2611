Afterword

This portfolio was designed to document my career journey and personal growth, while serving as a versatile resource adaptable to diverse career opportunities.
Although my programming journey is ongoing, bringing ideas into reality through iterative problem-solving has significantly deepened my commitment to web development.
Given that lecture required a commitment of half my weekends, I entered the program determined to make the learning experience genuinely rewarding.
Additionally, I set a personal goal to ask at least one question during each lecture to ensure active participation. I had so much fun customizing class assignments and sneaking in playful features.
Working on this portfolio naturally turned into a daily habit—I got so into it that I ended up coding for hours after class without even realizing it.
I’m so grateful to have been a part of this incredible experience!
