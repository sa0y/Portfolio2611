3. Automated Data Extraction Tool

【Situation】

同僚が作成したブラウザー拡張機能では、複数アイテムの情報を一括で一覧表示し、フィルターで必要なデータに絞り込んでダウンロードできました。しかし、セキュリティ上の理由で拡張機能が利用できなくなり、アイテムごとにタブを開いて個別に確認する必要が生じました。そのため、複数アイテムの情報をまとめて取り扱うのに手間がかかっていました。

【Task】

拡張機能の仕組みを参考にしながらも、許可されているローカルWeb環境内で動く仕組みを作成することにしました。

【Action】

開発ツールから必要なデータをExcel形式でダウンロードし、PowerShellで複数のファイルを統合して一覧で確認できるようにしました。

【Demonstration Using a Simulated Process】

SQL抽出デモを制作した記録
背景

授業で学んだSQLを業務改善の経験と結びつけて活用したいと考え、以前取り組んだ情報の一括取得・整理を題材にデモを制作しました。デモは実際の業務手順やツールを再現したものではなく、業務改善の考え方を紹介するため、架空データを使ってSQLで再構成しています。

工夫した点・苦労した点
1
タブの中にタブを設けた構成

外側のタブでBefore／Afterを切り替え、Before画面にはアイテムのバリエーションごとのタブを設けました。手作業で1件ずつ確認する流れと、複数データをまとめて表示する流れを比較できるようにしています。

2
SQLの実行結果を表示

ブラウザー上でSQLiteを実行し、クエリの結果を確認してExcel形式でダウンロードできるようにしました。

AIの活用について

SQL抽出デモの制作では、AIにJavaScriptのコード作成や修正を相談しました。SQLを実行して結果を表示する機能や、Excel形式でダウンロードする機能を実装し、動作を確認しながら調整しました。

今後の課題

SQLでデータを抽出するだけでなく、抽出結果を画面に表示したり、ファイルとして出力したりするまでの処理の流れを理解することが今後の課題です。
